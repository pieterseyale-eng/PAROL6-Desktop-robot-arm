# PAROL6 × 拓竹 P1S 打印分锅方案

设备：Bambu Lab P1S，标称成型空间 256 × 256 × 256 mm（[拓竹官方产品页](https://bambulab.com/en/p1)）。下表尺寸为当前仓库 STL 网格包围盒，单位 mm；并非推荐朝向下的实际占板尺寸。此方案是分锅草案，尚未在 Bambu Studio 实际排版。

## 打印前的选择

- 正常版主体件可逐件放入 P1S。整件 `Upper_arm.STL` 包围盒为 102 × 231 × 28 mm，长边沿平台 256 mm 方向摆放时只剩约 12.5 mm 总余量；建议单独打印并检查裙边、Brim 和边缘避让。
- 小平台目录中的分体上臂是整件上臂的替代方案，不要两套都打印。J1 标准件、rework blocker 和 small-bed 分体件也应按所选结构版本择一。
- 气动/真空夹爪附件暂不列入主体打印计划。
- 主体结构件建议使用 PETG，并遵循耗材厂商的温度、干燥要求和项目打印参数。具体温度、墙数、填充率要按实际耗材和切片结果设定，不能把单一值视为所有 PETG 通用参数。

## 小平台分体替代件

- 上臂：`SMALL_PRINT_BED/Upper_arm/Upper_arm_A_long_end` (82×162×28) 与 `Upper_arm_B_short_end` (77×88×28) **替代** `Upper_arm.STL`。可将 A 段与一锅主件同板，B 段与盖板/小件同板，但须在切片器确认占板与受力方向。
- J1：`J1_turret_rework_blocker_A_turret_end` (100×105×53) 与 `_B_arm_end` (114×80×75) 替代整体 rework blocker。按该目录 README 和小平台改装手册核定配套关系，不要当作额外加强件打印。

## P1S 上机核对

1. 在 Bambu Studio 选择 P1S 与实际喷嘴，逐锅导入并自动排版；逐件检查朝向、Brim、支撑、孔位和部件间距。
2. 先打印 `Elbow_part`、`J5_part` 等配合/承力复杂件样件，检查孔轴、轴承座、层间裂纹和装配尺寸，再批量打印。
3. PETG 先按线轴厂商说明干燥，并使用相应耗材配置；按拓竹对设备和耗材的建议控制腔温与通风。不同品牌耗材参数可能不同。
4. 项目打印说明和打印参数表作为强度设置参考；最终耗材、工时、支撑和裙边由切片器预览确认。提高填充率不能替代正确打印方向和外墙设计。
5. 打印时记录实际方向、耗材和失败/返工件；不同受力方向或支撑策略差异大的关键件可拆锅。

## 范围和限制

本方案根据 STL 网格包围盒作初步分组，未生成 3MF，也未计算实际耗材或工时。STL 自带方向未必是最佳打印方向；悬垂、支撑、Brim 与平台边缘余量必须由 Bambu Studio 确认。仓库包含替代件和夹爪附件，45 个 STL 不等于 45 个装机件；请按所选机械版本、README 和装配手册确定实际打印清单。
