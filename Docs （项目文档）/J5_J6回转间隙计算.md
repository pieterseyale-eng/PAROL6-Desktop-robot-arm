# J5 轴附近的 J6 组件回转间隙估算

记录日期：2026-11-06。单位均为 mm。本记录用于以后更换电机或调整 `J5_part` 长度时重新计算。

## 先看结果

| J5_part | J6 回转外廓 | 右端原有结构的保守平面间隙 |
| --- | --- | ---: |
| 未加长原版 | URDF 原版外廓 | **约 +2.78** |
| 未加长原版 | 原版外廓径向增加 23 | **约 −20.22（平面上重叠）** |
| 加长 30 mm 的 v2 | 原版外廓径向增加 23 | **约 +9.72** |

因此，若比较“都装新电机”的两种 J5_part，加长后右端原有结构的理论间隙增加约 **29.94 mm**：从重叠约 20.22 mm 变为留有约 9.72 mm。若比较“原版零件配原版电机”和“加长零件配新电机”，间隙从约 2.78 mm 增至约 9.72 mm，增加约 6.94 mm。

**这不是完整的无干涉证明。**本计算针对右端原有结构的二维回转包络。v2 新增的上方横板位于 X = 82～112 mm、Z = 58.1～74.0 mm；如果新电机/控制板也进入这个高度范围，横板可能先于右端结构发生干涉，必须另做三维装配检查。

## 数据从哪里来

1. URDF：`parol6_description （机器人模型说明）/parol6_description/parol6_flange.urdf`。`wrist_2_joint` 是 J5 回转关节，其子链接 `wrist_2_link` 使用 `meshes/arm/L5.STL`。在该链接局部坐标系中，回转轴为 Z 轴，故平面回转半径取 `sqrt(x² + y²)`。
2. 原版固定件：`STL （三维打印模型）/FOREARM （前臂）/J5_part.STL`。
3. 加长固定件：`STL （三维打印模型）/FOREARM （前臂）/J5_part_J6_plus30mm_v2.STL`。
4. 从 J5_part 的轴承圆孔截面得到轴心在其 STL 平面坐标中约为 **C = (28.5, 42.9)**。后续若重新定位轴承中心，应更新此值。
5. 用户给出的新 J6 组件相对原版向后凸出 **23 mm**。这里按最保守的简化处理：原版回转半径直接增加 23 mm。新增组件的实际三维模型尚未纳入 URDF。

## 计算过程

原版 URDF 网格的最大平面回转半径：

```text
R_original = max(sqrt(x_i² + y_i²)) = 52.34693 mm
R_new_est = R_original + 23 = 75.34693 mm
```

以轴心 C 为基准，在两版 `J5_part` 右端原有结构的网格顶点中求平面最近距离。为避开轴承附近本来就存在的横板，原版取 X > 82 mm，v2 取 X > 112 mm：

```text
D_original ≈ 55.12848 mm
D_v2       ≈ 85.06556 mm
```

采用 `间隙 = 固定件距轴最近距离 − 回转外廓最大半径`：

```text
原版固定件 + 原版外廓：55.12848 − 52.34693 =  +2.78155 mm
原版固定件 + 新外廓：55.12848 − 75.34693 = −20.21845 mm
v2 固定件 + 新外廓： 85.06556 − 75.34693 =  +9.71863 mm
```

v2 右端相对原版平移 30 mm，但“距轴最近距离”只增加 **29.93708 mm**，因为最邻近的网格位置并非严格处于轴心正右方。

## 下次如何重算

若只是改变 J6 径向外凸量 `e`，右端结构的快速估算为：

```text
间隙_原版固定件 = 55.12848 − (52.34693 + e)
间隙_v2固定件 = 85.06556 − (52.34693 + e)
```

若改变 `J5_part` 的加长量或切面位置，则重新从新 STL 测量轴心至右端原有结构的最近距离 `D`，再用 `D − R`。若新增部分的截面或新 J6 组件外形变化，必须检查**全部旋转角度和三维高度**，不能只沿用上述二维公式。

可在仓库根目录用以下只读脚本复算当前数字：

```python
from pathlib import Path
import numpy as np
import trimesh

root = Path(".")
axis_xy = np.array([28.5, 42.9])
l5 = trimesh.load(
    root / "parol6_description （机器人模型说明）"
    / "parol6_description/meshes/arm/L5.STL", force="mesh"
)
r_original = np.linalg.norm(l5.vertices[:, :2], axis=1).max() * 1000
r_new = r_original + 23.0

folder = root / "STL （三维打印模型）/FOREARM （前臂）"
for name, x_start in [
    ("J5_part.STL", 82.0),
    ("J5_part_J6_plus30mm_v2.STL", 112.0),
]:
    fixed = trimesh.load(folder / name, force="mesh")
    points = fixed.vertices[fixed.vertices[:, 0] > x_start]
    d = np.linalg.norm(points[:, :2] - axis_xy, axis=1).min()
    print(name, "D=", d, "原版外廓间隙=", d - r_original,
          "新外廓间隙=", d - r_new)
```

## 适用前提与待核对项

- URDF 的 `L5.STL` 是**原版**表示。它是否完整包含原电机、减速器、线束和插头的最远外廓，需要与实物或装配 CAD 核对；若遗漏，52.35 mm 会偏小。
- “加 23 mm”按最远半径增加处理。实际若沿不同方向凸出，应该将新组件外形与旋转轴放入同一坐标系，直接计算角点回转半径。
- `J5_part` 的打印坐标与 URDF 坐标没有在此正式配准；这里依据轴承圆孔中心作为共同旋转轴，仅比较平面半径。
- 对右端结构的 `D` 是从 STL **网格顶点**估算的，不是连续曲面精确最小距离；结果应视为约数。
- **新增横板的高度干涉尚未排除。**打印前应测量/建立新 J6 电机和控制板的安装姿态、三维外廓，再做全角度碰撞检查，并保留装配及打印误差余量。
