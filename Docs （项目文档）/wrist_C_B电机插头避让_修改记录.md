# wrist 电机插头避让：B、C 两面开槽

日期：2026-11-11。依据 J6 实物试装照片，两处插头与 `wrist.STL` 开口附近的侧壁干涉。用户根据开口俯视定位图确认需要切 **B 面（+X）与 C 面（+Y）**。

## 几何参数

- 原 STL 坐标单位：mm；开口位于最小 Z，即 `Z = 0.090815`。
- 电机方腔中心按截面取 `X = 30.05`、`Y = 29.10`。
- 每处槽口沿所在侧壁宽 **25 mm**，从开口沿电机轴线向内深 **25 mm**。切除终点为 `Z = 25.090815`。
- C 面槽口：X 为 `17.55～42.55`；切除刀具跨越 Y 为 `46.5～61.5`，穿透该面壁厚。
- B 面槽口：Y 为 `16.60～41.60`；切除刀具跨越 X 为 `48.5～63.5`，穿透该面壁厚。
- 刀具从开口外侧延伸 2 mm，确保完全切开开口边缘；模型的总体包围盒不变。
